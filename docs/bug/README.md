# Bug 记录（docs/bug/）

> **遇到 bug 先查这里。** 本目录按类型归档本项目踩过的坑与修复过程，防止重复踩坑。
> 规范见 `AGENTS.md` §13：遇到 bug 必查、修复后必记。

## 使用规则

1. **查询**：遇到 bug 时先按类型翻阅对应文档（按 `## BUG-xxx` 标题快速检索），
   若命中同根因，直接套用其"防坑指南"，不要重复排查。
2. **记录**：任何 bug 修复（含顺带修复）必须写入对应类型文档；无对应类型则新建
   `ui-<类型>.md` 并在此 README 索引补一行。
3. **格式**：每条记录严格按下方模板，信息越详细越好（现象 / 根因 / 文件组件 /
   修复过程 / 提交 / 验证 / 防坑），方便后续回溯。

## 分类索引

| 文档 | 覆盖范围 |
|---|---|
| [ui-layout.md](./ui-layout.md) | 布局 / 滚动 / 间距 / 尺寸（设置页双栏、工作台式布局） |
| [ui-theme.md](./ui-theme.md) | 主题面板全量控制（强调色/基础色/风格/标题字体/菜单外观/硬编码颜色） |
| [ui-css.md](./ui-css.md) | CSS 工具类 / 编译机制（Tailwind 预构建产物陷阱、工具类映射错误） |
| [ui-table.md](./ui-table.md) | 数据表格公共组件 `App.ui.dataTable`（排序/视图/过滤/选择） |
| [ui-i18n.md](./ui-i18n.md) | i18n 文案缺失 / 三语言 key 不一致 |

## 记录模板

```markdown
## BUG-<序号>: <一句话标题>

- 类型：<ui-layout / ui-theme / ui-css / ui-table / ui-i18n / ...>
- 严重度：<高 / 中 / 低>
- 发现时间：<YYYY-MM-DD>
- 修复提交：<commit hash>（<type>(<scope>): <标题>）
- 涉及文件：<逐个列出，含模块/组件路径>
- 涉及组件：<App.ui.* / 模块内组件 / 无>

### 现象
（用户视角看到什么、怎么复现）

### 根因
（技术根因，越具体越好，含选择器/特异性/代码片段等）

### 修复过程
（先做了什么、踩了什么坑、最终怎么改，精确到方法/属性/选择器）

### 验证
（如何确认修复有效：lint / test / 静态审计 / 预览手测步骤）

### 防坑指南
（以后新增/修改代码时如何避免再次踩坑，可执行的具体规则）
```
